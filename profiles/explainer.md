# Profile — Explainer / video essay

**One subject, argued to the bottom.** The viewer leaves understanding
something they didn't. This is the profile the framework was built from, so
it's the most complete.

| | |
|---|---|
| Length | 5–30 min |
| Presenter | Usually on camera, or voiceover over graphics |
| Backbone | Argument structure |
| Aspect | 16:9 typically; 9:16 for short-form variants |

## Structure

```
0–10s    hook — a counterintuitive claim or a number that shouldn't be true
         (chained beats, not one golden moment)
~15s     channel identification + the promise: what this video will settle
body     the argument, one step at a time, each step earning the next
         mid-video wake points every 2–3 min (declarative, not rhetorical)
close    the conclusion, including what remains unsettled
         one mirror question, offering two concrete options
```

### The chain technique
Every sentence should make the viewer want the next one. Each line leaves an
information gap the next line fills while opening a new one.

Write it in two passes: **first write the complete answer**, then **re-order it
into a question-answer chain**. Sequence by the viewer's reasoning path, not
your knowledge tree. Any sentence that closes completely with no gap gets
rewritten.

The limit: suspense must never be cheap. Every step delivers real value or the
audience feels manipulated and leaves.

## Trigger table preset

| # | Speaker is… | Treatment |
|---|---|---|
| 1 | Stating a surprising number | Stat card. **Verify first** |
| 2 | Introducing the subject | Title / section card |
| 3 | Describing X → Y | Morph or before/after |
| 4 | Defining a term | Big-word takeover |
| 5 | Describing a mechanism | Diagram, built progressively |
| 6 | Naming a concrete visible thing ≥4s | B-roll or media window showing **that** thing |
| 7 | Listing out loud | Sequential visuals on the beats |
| 8 | Changing topic | Section header |
| 9 | Emphasizing a word | Accent keyword in the subtitle |
| 10 | Concluding a step | Beat zoom |
| 11 | **Conceding a counterpoint** | **Nothing.** Clean face. Concession reads as honest only when undecorated |
| 12 | Citing a source | Source chip, bottom corner |

Row 11 is this profile's version of the do-nothing rule, and it's load-bearing:
an explainer's credibility comes from visibly granting the other side.

## Gate emphasis

- **Gate B is where the work is.** An explainer lives or dies on structure. A
  weak script cannot be edited into a good video.
- **Fact table is mandatory.** One verified number per claim, with its source,
  appended to the script.
- **Gate D catches over-decoration**, which is this genre's chronic failure.

## Failure modes

- **Front-loading context.** Explaining background before establishing why the
  viewer should care. Lead with the tension.
- **Decorating the concession.** See row 11.
- **Stacking numbers.** Three verified statistics beat eight. Parallel
  independent facts, never one synthesized citation.
- **Landing recaps.** Summarizing what you just said is where viewers leave.
  Write toward new information.
